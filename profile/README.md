# Gielinor Plugins

Plugins for RuneScape 3, built on Jagex's official
[Client API](https://developer.runescape.com/) and released through the in-game
Plugin Hub.

Every plugin follows Jagex's
[plugin guidelines](https://developer.runescape.com/rs/submission/guidelines.html)
and goes through Jagex's review before release.

## Plugins

| Plugin | What it does | Status |
|---|---|---|
| [Boss RNG](https://github.com/gielinor-plugins/boss-rng) | Tracks dry streaks for boss uniques | In development |

## What you can expect

- **Your data stays on your computer.** Unless a plugin says otherwise, nothing is
  sent anywhere.
- **Only the permissions a plugin really needs,** with a clear reason for each one.
- **Readable, commented code** that anyone can check.

## Getting a plugin

Open the Plugin Hub from the toolbox icon on your in-game ribbon, find the plugin, and
install it. Each plugin's page explains how to use it.

## Feedback and bugs

Open an issue on the plugin's repository, or email gielinorplugins@gmail.com.
